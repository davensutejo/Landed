I.
I. 痛点 · THE CHAOS

八项输入，几种语言，一张没人看得懂的 Excel。Eight inputs. One fragile spreadsheet.

To answer “what should I charge?”, a seller has to combine the tariff classification, the duty rate, VAT, freight bands, platform fees, FX, return costs and a local-language listing with its battery and labeling rules. Since 2025 that work can’t be skipped: the US suspended duty-free de minimis on 29 Aug 2025, and on 1 Jul 2026 the EU replaced its €150 exemption with a €3 duty per item tariff category. Every low-value parcel now needs an HS code.

    I.c RULE ZERO
    I.c 原则 · THE THESIS

    数字永远不来自大模型。Numbers never come from the model.

    Language models are good at language and bad at arithmetic they cannot check. On a benchmark of 200 binding U.S. customs rulings, the best frontier reasoning model picked the exact ten-digit tariff code one time in four. Consultants using AI on a task outside its frontier were nineteen points less likely to be right. So Landed splits the work. The model reads the messy product description, decides which tool to call, asks for what is missing (and, only where the code changes the price, the one question that settles it), and writes the local-language listing. Every rate, fee and price comes from deterministic code reading a table in which each row names its source where one exists, a status (verified, secondary or assumption) and the date we checked it. If a figure is not in the table, the agent says so instead of inventing one.

      III. ≤ 6 TOOL STEPS
      III. 方法 · THE AGENT LOOP

      从一句描述到一个可审计的价格。From one sentence to an auditable price.

      STEP I · DESCRIBE

      I. Describe

      “500 ml portable blender with a built-in battery plus a spare cup, ¥38, 0.6 kg. What should I charge in Germany for a 25% margin?” Pasted listings are handled as untrusted data, never as instructions.

      STEP II · CLASSIFY

      II. Classify

      Today this covers five candidate codes around blenders and mixers. It is only consulted where the code changes the money: a German order below €150 is priced for any product without asking. Where the code does matter, such as US duty, the agent asks for the attributes that decide it.

      STEP III · COMPUTE

      III. Compute

      The cost engine returns numbers. The model only explains them and never changes them.

      STEP IV · LOCALIZE

      IV. Localize

      Local-language copy, UN 3481 / PI 967 battery handling, food-contact declarations, and a flag when classifying the items as a retail set (GRI 3(b)) could lower the €3-per-category duty.

      IV.
      IV. 壁垒 · WHY THIS ISN’T AN EXCEL WRAPPER

      税率表人人可下载，判断逻辑不行。Anyone can download a tariff table. Judgment is harder to copy.

      01 · DATAIN BUILD

      只问会改变价格的问题Only questions that change the money

      Under the EU’s €3 regime the duty is €3 per kind of item in a parcel, whatever the code. So for a German order below €150 the agent prices any product straight away and never asks about motors or materials; what it watches is how many different kinds of goods share a parcel. The HS question only appears where the code changes money: US duty and the customs declaration itself. Orders above €150 are not priced, because the exact code’s conventional duty would apply. For those, it stores the attributes the HS legal notes and WCO GRI use to separate neighbouring codes (five codes in the blender family today, built by hand; extending from binding rulings, CBP CROSS and EU BTI, is in build).

      02 · METHODBUILT

      风险定价，而非加法Risk-buffered pricing

      Instead of COGS + freight + duty, the engine prices under uncertainty: 95% margin-at-risk, the chance of missing the target, deterministic shocks, and rule-aware tips: a multipack of the same item pays the €3 once (a ¥6, 50 g phone case drops from €9.24 to €5.87 per unit as a 2-pack, same margin), while a free gift of a different kind adds €3.

      03 · FLYWHEELROADMAP

      已清关先例回写Verified cleared precedents

      When a seller logs a shipment that cleared without adjustment, Landed stores the (spec, market, HS code, date) tuple. Over time this becomes a crowd-verified mapping that a calculator can’t replicate.

      04 · MONITORINGROADMAP

      法规漂移预警Regulatory drift alerts

      Because every rate carries a snapshot_date, saved SKUs can be recalculated whenever a duty, fee or FX band moves, flagging any SKU that falls below its margin floor. The EU’s €3 regime is scheduled to end on 1 Jul 2028, which is exactly this kind of change.
